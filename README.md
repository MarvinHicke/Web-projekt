***Kurze Überblick von wichtigen Informationen:*** 

- Technologie-Stack: es muss auf PHP in der XAMPP-Umgebung laufen

- JavaScript, externe Biblotheken und Templates-Engines sind NICHT erlaubt. Außer in Use-Case 25

- Lokale Assets bspw. externe Abhängigkeiten wie Bootstrap oder Google Fonts dürfen NICHT direkt aus dem Internet geladen werden, sondern Lokal ins Projektverzeichnis eingebunden werden 

- All Input Is Evil: Alles muss als gefährlich angesehen werden und daher müssen immer Sicherheitsvorkehrungen getroffen werden (bspw. Prepared Statements)

- Für alle Elemente im Code muss die PHPDoc-Style Inline-Kommentare geschrieben werden

- Nichts an der DB verändern, da alles vorgegeben ist (keine zusätzlichen Tabellen erstellen)
